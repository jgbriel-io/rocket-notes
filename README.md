# Rocket Notes

Aplicação de front-end (React + Vite) para criar e organizar notas com tags, autenticação (sign in/sign up) e perfil de usuário. Feito durante a trilha de React da Rocketseat, consumindo uma API REST fornecida pelo curso.

## Stack

- React 18, React Router, styled-components

## Rodando localmente

\`\`\`bash
npm install
npm run dev
\`\`\`

Requer a API do curso rodando localmente (não incluída neste repositório).

Exercício de curso — Rocketseat (trilha React).
